# ExpenseBot 💰

ExpenseBot — это Telegram-бот для учёта расходов и доходов. Он помогает быстро записывать траты, видеть сумму за сегодня и понимать, куда уходят деньги.

## Что умеет бот

- добавлять расходы в формате: `кофе 450`;
- добавлять доходы в формате: `зарплата 250000`;
- показывать расходы за сегодня;
- показывать итоги за месяц;
- показывать общую сумму;
- сохранять записи в SQLite;
- использовать Telegram inline keyboard.

## Как работает

Пример:

```text
кофе 450
```

Бот понимает это как расход и сохраняет запись:

```text
☕ Кофе — 450 ₸
```

## Запуск

1. Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите бота:

```bash
npm run dev
```

## Команды

- `/start` — начать работу;
- `/today` — показать расходы за сегодня;
- `/month` — показать итоги за месяц;
- `/help` — подсказка по формату записи.

## Форма записи

```text
описание сумма
```

Примеры:

```text
кофе 450
еда 3200
такси 1800
зарплата 250000
```
